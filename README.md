# CV BeruangLaut.ID — Company Portfolio

A premium, futuristic company portfolio for **CV BeruangLaut.ID**, focused on Artificial Intelligence, Robotics, Automation, IoT, Computer Vision, and Software Engineering.

## Stack

- Next.js 16
- React 19
- TypeScript
- Custom CSS
- No UI framework dependency
- No database required for the initial portfolio

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm start
```

## Deploy to Vercel

Push the project to GitHub and import the repository into Vercel. No additional server is required for the current version.

## Important

Project information in the portfolio is based on the supplied project logbook. Some projects intentionally use generalized client descriptions where the source itself does not expose a company/client name.
